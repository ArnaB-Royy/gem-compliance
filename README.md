## 🔴 The Problem

> **Every time the government buys something through GeM, someone has to manually verify the vendor.**
> That means opening 10+ government portals, cross-checking GST, PAN, EPFO, MSME, ITR, and OEM documents one by one — by hand.

```
❌ THE OLD WAY
────────────────────────────────────────────────────────────────
  Vendor submits bid on GeM
            ↓
  Officer opens GST portal      ← 30–45 minutes
            ↓
  Officer opens EPFO portal     ← another 30 minutes
            ↓
  Officer checks PAN database   ← another 20 minutes
            ↓
  Officer checks MSME registry  ← another 20 minutes
            ↓
  Repeat for every vendor. Every tender. Every time.
            ↓
  2–4 weeks per tender. Human errors. No audit trail.
  Fraud slips through. Procurement stalls. Taxpayer money at risk.
────────────────────────────────────────────────────────────────
```

---

## ✅ The Solution

```
✅ WITH GEM COMPLIANCE
────────────────────────────────────────────────────────────────
  Vendor submits bid on GeM
            ↓
  AI reads all documents instantly
  (GST · PAN · EPFO · Udyam · ITR · OEM)
            ↓
  Cross-verifies names, IDs, dates across all docs
  Checks blacklists. Detects mismatches. Flags anomalies.
            ↓
  Generates compliance score 0–100 with full explanation
            ↓
  Officer reviews AI summary → makes final decision
            ↓
  Minutes. Accurate. Tamper-proof. Fully auditable.
────────────────────────────────────────────────────────────────
```

**The AI does the grunt work. The officer does what only a human should — make the final call.**

## 👷 What the Officer's Job Looks Like Now

> **Before:** Open 10 portals. Copy-paste data. Manually cross-check. Write notes. Repeat for every vendor. Spend weeks on paperwork.

> **After:** Open one dashboard. Read the AI's findings. Agree or override. Done.

```
WHAT THE OFFICER NO LONGER HAS TO DO        WHAT THE OFFICER NOW FOCUSES ON
─────────────────────────────────────        ────────────────────────────────
❌ Manually open 10+ government portals      ✅ Review AI-generated summary
❌ Copy-paste data across tabs               ✅ Read plain English explanation
❌ Cross-check names and IDs by hand         ✅ Spot-check flagged anomalies
❌ Search blacklist databases manually       ✅ Apply domain expertise & judgment
❌ Create audit logs manually                ✅ Approve or Reject with one click
❌ Write compliance reports from scratch     ✅ Audit trail auto-generated
❌ Spend 2–4 weeks per tender               ✅ Process multiple tenders per day
```

**The officer goes from being a data-entry clerk to an actual decision maker.**
Their expertise is used where it matters — not wasted on repetitive lookups.

## ✨ Key Innovations

| | Feature | What It Does | Why It Matters |
|---|---|---|---|
| 🧠 | **Explainable AI (XAI)** | Every decision explained in plain English | Officers understand WHY, not just what the score is |
| 🔤 | **Fuzzy Name Matching** | Cross-document name similarity with % score | Catches "Suresh Fabricators" vs "S Fabricators & Co" — real fraud pattern |
| 🔒 | **Zero Trust Hashing** | SHA hash on every action | Tamper-proof — no one can alter records after the fact |
| 📴 | **Offline First** | AI runs locally | Works even without internet — critical for government setups |
| 🛡️ | **Cross-Ministry Blacklist** | Checks all ministry databases | Catches blacklisted vendors even if they changed names |
| 📊 | **AI Confidence Calibration** | Uncertain fields flagged automatically | Human reviews edge cases — AI doesn't guess blindly |
| 🗃️ | **DPDPA Compliant** | Docs processed and auto-deleted locally | Legally compliant with India's data protection law |
| 👁️ | **Live OCR Preview** | Watch AI extract data in real time | Full transparency — vendor sees exactly what AI read |

## 🏃 Run Locally

```bash
# Clone
git clone https://github.com/ArnaB-Royy/gem-compliance.git
cd gem-compliance

# Frontend
cd Frontend
npm install
npm run dev
# → http://localhost:5173

# Backend (new terminal)
cd Backend
npm install
cp .env.example .env
# Add your Gemini API key to .env
node server.js
# → http://localhost:3000
```
